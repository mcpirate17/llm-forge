# Active-state and session-close test migration

The six tests in `src/conductor/test_active_state.py` and eight named tests in
`src/conductor/test_session_close.py` moved to Rust-owned PyO3 contract targets.
The session validation test has three parameter rows, giving 16 original pytest
executions and 14 Rust test functions. All fixture construction, callbacks,
parameter rows, and assertions live in Rust. The tests invoke the production
Python APIs through PyO3 and do not import either retired test module.

The session fixture initializes Git and ownership data inside a temporary
repository. Strict Rust callbacks use Python signature binding to preserve
positional and keyword call shapes; the memory callbacks record real Python
`Path` objects in Python lists for exact container comparisons. The active
state generated by session close reads the selected fixture repository.

Before migration, the original suites passed 16/16 executions. The focused
Rust targets pass 6/6 and 8/8 with offline Cargo, two build jobs, one test
thread, CUDA masked, and the pinned Rust 1.98 toolchain. Scoped Clippy with
`-D warnings`, exact-file rustfmt, and the 1250-line/100-line limits pass.
The Forge issue list had no open issue covering this migration.

No active module imports either retired Python test module, and no active
test selector names either path. Historical mutation campaign manifests and
the candidate-review grandfathered node-ID inventory retain the original
names as provenance. Those historical records remain unchanged.
