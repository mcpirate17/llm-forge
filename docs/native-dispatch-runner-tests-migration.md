# Dispatch runner and Claude PreToolUse contract migration

The 25 named cases in `src/tooling/hooks/dispatch/test_runner.py` are covered by Rust-owned PyO3 contracts in `native/conductor-native/tests/python_contracts_dispatch_runner_execution.rs` (11) and `python_contracts_dispatch_runner_protocol.rs` (14). The two named cases in `src/tooling/hooks/claude/test_pre_bash_e2e.py` are covered by `python_contracts_claude_pre_bash_e2e.rs`. All 27 original pytest cases passed before the port. The corresponding 27 Rust cases passed with two Cargo jobs, one test thread, CUDA masked, and the pinned Forge 0.8.1 binary. Scoped Clippy passed with warnings denied.

Execution contracts preserve adapter exception strings, detached-thread stdout rejection, exact Python dictionary returns, per-thread input and output capture, `SystemExit` handling, one-second timeout and parallel completion bound, executable subprocess bodies, payload and `PROJECT_DIR` propagation, and the SessionStart exposure line. Protocol contracts preserve registry selection order, native hook exclusion and splice order, malformed input, host-specific Codex normalization, CLI stdout/stderr behavior, quiet telemetry labels, and exact Python Path and container comparisons. The Claude target invokes the real `pre-bash.sh` with each original command string and asserts the returned JSON decision and reason in Rust. Its child process has the original 30-second bound.

Python production modules are invoked through PyO3; fixture construction and assertions belong to the Rust targets. `python_contracts/dispatch_runner_support.rs` holds scoped environment and attribute restoration plus signature-checked callback fixtures. No Rust test launches a retired pytest suite, external service, or model.

Independent parity review and consumer inventory passed. The two original Python test modules were then retired; no production module imports either test module or its private helpers. The three exact Rust targets and scoped Clippy were rerun after retirement. Historical references to the original filenames in migration notes remain provenance.
